# Introduction

REST API для TaskMate — системы управления задачами для автосалонов.

<aside>
    <strong>Base URL</strong>: <code>http://localhost:8007</code>
</aside>

    API для управления задачами, сменами, автосалонами и пользователями.

    Все даты передаются в формате ISO 8601 UTC (`2024-01-15T10:30:00Z`).

    Аутентификация через Laravel Sanctum (Bearer token).
